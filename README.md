# Heroes - PixiJS Game

Игровой проект на базе PixiJS с использованием Vite в качестве сборщика.

## Технологии

- **PixiJS** - высокопроизводительный 2D движок для WebGL
- **Vite** - быстрый сборщик前端-приложений

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура проекта

```
heroes/
├── src/
│   └── main.js       # Основной файл приложения
├── index.html        # HTML шаблон
├── vite.config.js    # Конфигурация Vite
└── package.json      # Зависимости проекта
```

## Пример

Приложение создаёт:
- Игровое поле на весь экран
- Заголовок "Heroes Game"
- Анимированного героя (зелёный круг)
