# Heroes of Might and Magic: Arena

Пошаговая тактическая боевая система в стиле **Heroes of Might and Magic III**, реализованная на **TypeScript + PixiJS**.

## Описание

Проект воспроизводит ключевые механики боевой системы HoMM3: гексагональное поле, очерёдность ходов по инициативе, перемещение по гексам, атака, защита, ожидание, а также базовый ИИ противника.

## Технологии

| Технология     | Назначение                             |
| -------------- | -------------------------------------- |
| **PixiJS 8**   | Рендеринг, анимации, событийная модель |
| **TypeScript** | Строгая типизация, strict mode         |
| **Vite**       | Сборка и dev-сервер                    |

## Установка и запуск

```bash
npm install      # Установка зависимостей
npm run dev      # Запуск dev-сервера (откроет браузер)
npm run build    # Продакшн-сборка
npm run preview  # Предпросмотр собранной сборки
```

## Реализованные механики

### Боевая система

- **Гексагональное поле** 12×10 с подсветкой доступных для перемещения гексов
- **Очередь инициатив** — визуальная панель порядка ходов с маркерами раундов (R2, R3…)
- **Перемещение** — BFS-поиск пути, пошаговая анимация по цепочке смежных гексов (150 мс/гекс)
- **Атака** — формула урона HoMM3 (атака vs защита, +5%/−2.5% за пункт, максимум ±30%)
- **Действия за ход**: Атака, Защита (−50% входящего урона), Ожидание (перенос в конец очереди), Перемещение
- **Полоски здоровья** над стеками (зелёный → жёлтый → красный)
- **Комбинация «движение + атака»** — клик по врагу в пределах досягаемости за один ход
- **Экран победы/поражения** с кнопкой перезапуска

### ИИ противника

- Автоматический ход для всех стеков защищающейся стороны
- Приоритеты: атака без движения → движение + атака → приближение к врагу → защита
- BFS-поиск ближайшей позиции для атаки
- UI блокируется во время хода ИИ

### UI-компоненты

- **TurnOrderPanel** — очередь ходов (12 слотов)
- **ActionPanel** — кнопки действий (Атака, Защита, Ожидание, Перемещение, Пропуск хода)
- **CreatureInfoPanel** — информация о существе (имя на русском, уровень, атака, защита, урон, здоровье, инициатива, скорость, количество)
- **DebugPanel** — отладочный журнал перемещений игрока

### Алгоритм очереди ходов

Панель очереди ходов использует **фиксированный массив из 12 слотов** с алгоритмом сдвига:

- **Инициализация**: `[Лучник, К1, К2, К3, R2, Лучник, К1, К2, К3, R3, Лучник, К1]`
- **Обычный ход**: `shift()` → `push(actingStack)` в конец
- **Wait (Ожидание)**: `shift()` → вставка стека **перед первой меткой раунда** (конец текущего раунда)
- **Новый раунд**: полная пересборка очереди с правильным номером раунда
- **Гибель**: фильтрация всех копий мёртвого стека
